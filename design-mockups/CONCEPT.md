## 1. Design Read

> Reading this as: **бренд-сайт производителя мебели на заказ** (HoReCa + residential, Черногория → EU) для закупщиков отелей/ресторанов и владельцев квартир, с **кинематографичным тёмным языком «вечернего шоурума»**, опираясь на Next.js 16 + CSS Modules + нативные CSS/View Transitions + одна GSAP-сцена.

Диалы: **DESIGN_VARIANCE 7 · MOTION_INTENSITY 7 · VISUAL_DENSITY 3**.

Физическая сцена (обязательная перед выбором тёмной темы): менеджер по закупкам отеля открывает сайт в 22:00 с ноутбука после дня объезда объектов; экран должен ощущаться как витрина мебельного шоурума ночью — тёмное стекло, внутри тепло светятся кухни. Тёмная тема здесь не «потому что модно», а потому что продукт Артидома буквально светится: LED-подсветка полок и шкафов — фирменный приём, видный на реальных фото их кухонь.

## 2. Идея: «Свет — второй материал»

Сайт = вечерний шоурум на Адриатике. Наследует утверждённый спек `2026-07-16-night-showroom-design-spec.md` и усиливает его выводами ресерча 2026:

- **Одна сильная метафора на весь сайт** (тренд 2026: restraint over maximalism — побеждают сайты с одной визуальной идеей). Метафора: свет включается, свет ведёт, свет подсвечивает. Всё движение на сайте — это поведение света, а не набор эффектов.
- **Реальные фото вместо рендеров** (тренд 2026: анти-AI-slop, аутентичность как премиум-сигнал). У Артидома есть реальные фото цеха и объектов — это преимущество перед конкурентами с рендерами.
- **Нативный моушн вместо библиотек** (тренд 2026: View Transitions API + CSS scroll-driven animations; GSAP только там, где нативного не хватает — одна пин-сцена).

### Почему не альтернативы

- **A. «Editorial Manufacture»** (светлая швейцарская редакционная, Lusano/Andreu World) — сильное направление, но: уже половина премиальных мебельных сайтов там, и у нас есть утверждённый Night Showroom. Оставляем как запасной вариант, если тёмная тема плохо покажет себя в Метрике после фазы 1.
- **C. «Kinetic Type + Proof»** (типографика + цифры как дизайн) — элементы забраны сюда (крупные цифры этапов в Unbounded), но как самостоятельное направление слишком «агентское» для производителя.

## 3. Визуальная система

### Цвет (стратегия: Drenched dark + один акцент)

Поверхность САМА является цветом — тёплый графит. Акцент один: янтарь (свет). ОКLCH-токены из утверждённого спека:

```css
--surface-night:    oklch(0.17 0.01 50);   /* тёплый графит, фон */
--surface-elevated: oklch(0.22 0.012 55);  /* приподнятые панели */
--ink-warm:         oklch(0.95 0.015 85);  /* основной текст */
--ink-dim:          oklch(0.72 0.02 75);   /* вторичный текст (контраст ~7:1) */
--amber-light:      oklch(0.78 0.14 75);   /* свет: CTA, акценты */
--amber-deep:       oklch(0.62 0.15 60);   /* hover-состояние янтаря */
--glow-under:       0 12px 40px -12px oklch(0.78 0.14 75 / 0.25); /* подсветка снизу */
--radius:           12px;  /* ОДИН радиус на всё: кнопки, карточки, фото, инпуты */
```

Ключевой фирменный ход: **«подсветка снизу» вместо теней**. Элементы не отбрасывают тень — они светятся снизу, как шкафы с LED-лентой. Никаких серых drop-shadow.

### Типографика

- **Unbounded** 500/600 — дисплейная: H1, заголовки секций, крупные цифры этапов. Широкая геометрическая, есть кириллица (SR/RU критично). Трекинг не tighter −0.01em.
- **Commissioner** 400/500/600 — текст, UI, формы. Тихий гротеск, кириллица, variable.
- Пара по контрастной оси (широкая display vs обычный гротеск), обе вне reflex-reject списков. Outfit и Cormorant уходят.
- Шкала: модульная ≥1.25, `clamp()` флюид; H1 потолок 4.5rem (72px) — ниже лимита 6rem.

### Форма и плотность

- Один радиус 12px на всё (shape lock). Никаких 24–40px.
- Плотность 3 (галерейная): крупные вертикальные ритмы `clamp(6rem, 12vw, 10rem)` между секциями.
- Очень тихое зерно (film grain) на фиксированном `pointer-events:none` слое, opacity 0.04 — тактильность против «пластикового» AI-вида.

## 4. Моушн-концепция: «Свет ведёт»

Роль движения: **навигация и фокус** (свет направляет взгляд), не декорация. Три кандидата были: (1) кинетическая типографика, (2) параллакс-сцены, (3) свет как проводник. Выбран (3): единственный, который растёт из продукта (LED-подсветка — их фирменный приём), а не из моды.

### v2: усиление (после ревью v1 «недостаточно wow»)

V1 был компетентным, но безопасным: одна пин-сцена на весь сайт — мало для MOTION 7. В v2 метафора света сыграна по-крупному, но всё ещё ОДНОЙ идеей:

| Слой | Что | Триггер | Параметры | Reduced motion |
|---|---|---|---|---|
| **0. Двери шоурума** | Две тёмные панели разъезжаются, слово Artidom гаснет | load, один раз за сессию (в проде) | 850ms ease-in-out-brand, JS-инъекция (no-JS = нет veil) | нет veil |
| **1. Hero «Свет включается»** | Тёмная комната → LED-зоны на фото вспыхивают по очереди (3 radial-вспышки mix-blend screen) → яркость фото 0.3→1 → H1 из клип-маски, подпись, CTA | load | вспышки 950ms stagger 200ms; фото 1.2s; H1 750ms stagger 80ms; всё ~2.9s | мгновенная видимость |
| **2. Фонарик (spotlight)** | Тёплое пятно света (720px radial, mix-blend screen) следует за курсором с lerp 0.09 — посетитель «светит» на мебель | pointermove, desktop fine-pointer | постоянно, opacity 0.09 | off; touch: off |
| **3. Сцена «Как мы работаем»** | Пин: нить (SVG stroke-dashoffset scrub) зажигает узлы; каждый новый этап входит через диагональный **световой паш** по фото | scroll scrub | GSAP, `start: top top`, pin, scrub 1, `+=300%`; sweep 550ms | статичный список |
| **4. View Transitions** | Фото featured-кейса перелетает с главной в сетку projects (`view-transition-name`, cross-document) | navigation | нативно, Chrome 126+ | нативный fallback |
| **5. Микро-слой** | Секторы-строки: hover-превью с наклоном по скорости курсора + wipe-смена кадра (clip-path); магнитные CTA ≤6px; `:active` scale(0.97); FAQ `::details-content` | hover/click | UI ≤250ms ease-out-brand | opacity ≤200ms |

Кодекс: только `transform/opacity/clip-path/filter`; нет `transition: all`, `ease-in`, `scale(0)`; нет бесконечных циклов; hover под `@media (hover:hover) and (pointer:fine)`; GSAP только для сцены 3; контент виден без JS (reveal-классы ставит JS, veil инжектит JS).

Почему это не «ещё один набор эффектов»: каждый слой — одно и то же действие (свет включается / свет ведёт / свет подсвечивает), повторённое на разных масштабах. Это и есть вывод ресерча 2026: один interaction model, доведённый до блеска, вместо россыпи приёмов.

Жёсткие правила моушн-кодекса: только `transform/opacity/clip-path/filter`; нет `transition: all`, `ease-in`, `scale(0)`; нет бесконечных циклов; hover только под `@media (hover:hover) and (pointer:fine)`; GSAP только для сцены 2; контент виден без JS.

## 7. Анти-слоп чек (pre-flight по taste-skill)

- Без em-dash в новом UI-хроме; существующие тексты JSON не трогаем (SEO-инвариант важнее)
- Без градиентного текста, глассморфизма, декоративных сеток, пилюль на фото, scroll-cue, «01/02/03»- eyebrow, карточек-одинаковок
- Все фото — реальные (цех, объекты), ни одного стокового
- Один акцентный цвет на всю страницу; одна тема (dark) без инверсий секций
- Кнопки: контраст янтарь/графит ≈ 5:1+, `:active` scale(0.97), фокус-ринг 2px

## 8. SEO-инварианты (не трогаем)

URL/slugs, H1, все тексты секций, meta, JSON-LD (HowTo шаги = тексты «How we work»), hreflang, sitemap, имена полей формы (`name, phone, email, company, message, website`), события аналитики (`contact_form_submit`, `cta_request_estimate`, `phone_click`, `whatsapp_click`, `viber_click`), `data-speakable`. Контент читается без JS. Фазовый раскат с мониторингом Яндекс.Вебмастера (у клиента Google 0 страниц, Яндекс 14+).

## 9. Что в макете / что нужно от владельца

В макете: вся главная + страница проектов, реальные тексты EN, реальные фото из `public/`, рабочие анимации (GSAP CDN только в макете). Hero-фото — из папки владельца `photo/примеры` (вечернее, с LED).

Нужно от владельца (как и в спеке): 3–5 вечерних фото кухонь ≥1800px горизонтальных (текущее hero — квадратное, обрезано), решение по логотипу-wordmark (Unbounded 500 в макете), имена/локации проектов для фазы 3.
